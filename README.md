# LANDGUARD

**Your property. Watched locally.**

LANDGUARD is an MVP for remote property monitoring, evidence capture, inspections, alerts, and local service coordination for property owners.

## Run locally

pip install -r requirements.txt
streamlit run app.py

## Demo
Use the sidebar role selector to explore Customer, Field Agent, and Admin workflows.

## MVP limitations
- Demo users and properties are seeded in SQLite.
- Authentication, payments, native mobile GPS enforcement, offline mode, and production cloud storage are deferred to V2.
- AI findings are advisory and require human review.
- Monitoring status is not a title certificate, legal opinion, valuation, or guarantee against encroachment.

## Product direction
V2 will add real customer accounts, field-agent GPS/evidence controls, property intelligence, a permanent Property Passport, NRI notifications, and a local services marketplace.
